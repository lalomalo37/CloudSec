
A computer network is a digital telecommunications network which allows nodes to share resources

A client is a device that accesses a service made available by a server

A server is a device that provides functions or services for clients

A server or client can be referred to endpoints or end hosts

Switches:
- Have many network interfaces/ports for end hosts to connect to (usually 24+).
- Provide connectivity to hosts within the same LAN (Local Area Network)
- Do not provide connectivity between LANs or over the internet

Routers:
- Have fewer network interfaces than switches
- Are used to provide connectivity between LANs
- Routers are used to send data over the internet

Firewalls:
- Monitor and control network traffic based on configured rules.
- Can be placed 'inside' the networks, or 'outside the network' meaning they can be placed after or before the data reaches the router.
- Are known as 'Next generation Firewallks' when they include more modern and advanced filtering capabilities

Network firewalls:
Are hardware devices that filter traffic between networks

Host-based firewalls:
Are software applications that filter traffic entering and exiting a host like a PC.
